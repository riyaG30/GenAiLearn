🐍 Python ramp-up — from JS + C++ 6–8 hrs ▾
Good news: JS + C++ is genuinely strong preparation. You already know async/await, closures, type systems, references, event loops. Python's async/await works almost identically to JS. List comprehensions = .map()/.filter(). Pydantic = TypeScript-style runtime types. C++ rigor makes your Python look more like senior FAANG code than "data science Jupyter Python." You're 3-4 hours behind a Python native at Week 1; by Week 6 the gap is gone.

🔌 MCP — Model Context Protocol 2026 Standard ▾
Why MCP is suddenly everywhere
  • Open standard from Anthropic (Nov 2024) — now natively supported by Claude, ChatGPT, Gemini, Cursor, Windsurf, JetBrains, Vercel AI SDK
  • Donated to Linux Foundation in Dec 2025 — vendor-neutral governance
  • 78% of enterprise AI teams report at least one MCP-backed agent in production (Q1 2026 survey)
  • 9,400+ public MCP servers; 7.8× year-over-year growth
  • Replaces per-vendor function calling — "USB-C for AI tools"
Core concepts to master
  • Architecture: Hosts (Claude Desktop, Cursor, VS Code) ↔ Clients ↔ Servers
  • JSON-RPC 2.0 as the wire protocol
  • Three primitives: Tools (actions), Resources (read-only data), Prompts (structured workflows)
  • Two transports: stdio (local subprocess) vs Streamable HTTP (remote, scaling)
  • OAuth 2.1 for production remote servers (2026 standard)
  • MCP Inspector (npx @modelcontextprotocol/inspector) for debugging
Hands-on (Phase 3 add-on, ~6 hrs total)
  • Install Claude Desktop, connect a public MCP server (e.g. filesystem, GitHub) — see it work end-to-end
  • Build ONE MCP server in Python (FastMCP SDK) exposing 2-3 tools from your showcase corpus
  • Test with MCP Inspector before wiring to a client
  • Add it to your showcase repo — instantly differentiates you from candidates still hand-rolling function calls
Your edge: ERG uses pre-MCP-era custom tool binding via Script Includes.
